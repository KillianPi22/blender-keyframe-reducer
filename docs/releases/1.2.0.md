# Keyframe Reducer 1.2.0 — development, unpublished

Adds **Simplify Curve** alongside **Key Reducer** in the Graph Editor. Simplify removes redundant selected transform keys within visible position, rotation and scale tolerances. Surviving keys keep their values and interpolation; manual tangent keys are protected by default. Automatic interior handles may be recalculated. Separate selected runs, outside handles and unrelated channels/slots are preserved. Position, scale and Euler axes are independent; quaternion WXYZ channels stay grouped and use angular error.

Both tools work on a copy and recalculate from the protected original, including when switching tools or scope. **Simplify New Selection** explicitly uses the displayed Action as a new source. Compare **Original / Simplified**, choose **Keep Copy for Editing**, or use **Restore Original** to end comparison. Restore retains the generated Action for recovery.

This is a manual workflow. Automatic debounced preview, smoothing, general scalar properties and world-space contact protection are not included. Error validation is sampled and local, not a continuous bound. Manual edits to the result must follow **Keep Copy for Editing**.

Validation uses generated fixtures in isolated Blender 5.2.1 LTS profiles: numerical shape checks, subframe overshoot, independent axes, disjoint selections, manual tangents, marked keys, Euler turns, quaternion orientation, unsupported curves, A/B/A recalculation, empty-selection failure, comparison, undo/redo, save/reopen and package reload. Historical release ZIPs remain unchanged. No private mocap scene was used for this development change.

All **125 checks** passed on 2026-11-21: 25 core, 28 selection, 43 simplify, 17 historical upgrade and 12 current-version upgrade checks. Native installation over 1.1.1 and cached-module reload were both exercised. A visual Graph Editor smoke test simplified a generated 81-key Bezier curve to 21 keys, verified Original / Simplified comparison, then restored the original Action. These synthetic checks do not substitute for review on production mocap.

`release.json` deliberately remains at 1.1.1. Building this development ZIP does not request publication.
