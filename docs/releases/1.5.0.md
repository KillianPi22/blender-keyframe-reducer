# Keyframe Reducer 1.5.0 — development, unpublished

Animators can now adjust curve density without pressing Recalculate after every
change. In the Graph Editor, choose **Simplify Curve / Editable Bezier**, select
keys and start **Interactive Preview**. The **Reduction** slider automatically
recalculates from a captured source and shows the remaining key count. Original /
Preview, Apply and Cancel remain at fixed positions while progress changes.

Reduction multiplies the base shape-change limits; it is not a forced key count.
For example, a 0.5° rotation limit becomes 1° at Reduction 2. The curve-fitting
algorithm and defaults from 1.4 remain unchanged. Key Reducer and Keep Existing
Handles retain their manual workflow.

Changes are debounced and calculations yield to Blender's main thread. Only the
latest completed request becomes visible. Apply is disabled while an update is
pending or failed. Captured bones, selected runs, gaps and unrelated slots stay
protected; every calculation starts from the immutable source. Cancel restores
the starting assignment and selections. Apply keeps an editable Action and ends
the session. **Apply before editing keys or saving:** saving cancels an unapplied
preview. Undo/redo, reload and file changes clean temporary runtime state; edited
or externally referenced previews are retained as user data.

All seven suites pass **253 checks in Blender 5.2.1 LTS**, including 45 preview
checks for cancellation, superseded requests, source-based determinism, frozen
scope, source/preview edits, shared results, full quaternions, save/reopen,
undo/redo and reload. Existing numerical, selection and upgrade checks pass.

The native Graph Editor was also exercised with the installed ZIP: dragging and
editing Reduction triggered automatic updates, a generated selected curve changed
from 331 to 13 keys at Reduction 1 and to 11 at Reduction 2, Original / Preview
switched correctly, Cancel restored the dense source, and Apply retained the
editable result. Reinstalling during an active preview restored the source and
removed the runtime session.

A synthetic 744,600-key Action with one selected bone takes about 2.3–2.8 seconds
of computation per update, plus Blender timer scheduling. Most callbacks stay
near 12 ms, but whole-Action copies and cleanup can pause longer. Full-rig instant
updates are not claimed. See [preview measurements](../INTERACTIVE_PREVIEW.md).
The production Minotaur scene was not used; continuous or world-space fidelity
and foot-contact locking remain outside this release.

This is a development build. `release.json` remains 1.1.1; a source update does
not change the stable download. GitHub's validation workflow builds the current
installable ZIP as an artifact. Website deployment is separate.
