# Keyframe Reducer 1.1.1

Install `keyframe_reducer-1.1.1.zip` using Blender's **Install from Disk** command. The delivery pack also includes English and French guides.

This is the existing stable baseline, including strict selected-key reduction and the in-session update fix. The add-on source is unchanged from the original 1.1.1 release. Interactive Graph Editor preview is planned and is not included in this version.

The public delivery pack excludes private character scenes. The unchanged historical guides describe the original private scene bundle; that fixture is not part of this public download. Source code and synthetic tests are available in the repository.

The portable runner passed 70 checks locally in Blender 5.2.1 LTS on 2026-11-20: 25 core/integration, 28 selection and 17 historical upgrade checks. The GitHub workflow validates package structure and version consistency; it does not run Blender.

Packaging is reproducible from this repository. The ZIP metadata and public delivery-pack contents differ from the original private delivery. Check `SHA256SUMS.txt` for the current archives.
