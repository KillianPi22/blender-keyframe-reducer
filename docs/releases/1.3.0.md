# Keyframe Reducer 1.3.0 — development, unpublished

Dense bone curves can retain too many points when simplification begins with
linear segments and leaves existing tangents in place. **Simplify Curve > Curve
Style: Editable Bezier** now fits shared cubic tangents and adds source key times
only where sampled error requires them. Surviving interior handles are Aligned
for editing. Selected manual tangents are explicitly rebuilt; boundary outward
handles, unselected gaps, retained key values/times and the original Action remain
protected. Keep Existing Handles retains the 1.2 behavior and stays the default.

Fixes Selected Bones Only for Blender 5.2 by using pose-bone selection. Result
statistics now count the filtered scope. Per-curve counts and sampled errors are
saved in the result Action's `kr_report` property. Existing kr operators and
settings remain compatible; new fields default to the legacy behavior.

The generated 241-key bone rotation compares 54 legacy keys with 12 fitted keys
at the same 0.5° tolerance; the fitted error measured at eighth frames is 0.266°.
The six suites pass 167 checks in Blender 5.2.1 LTS, including an actual generated
armature, disjoint runs, aligned tangents, marked poses, Euler turns, grouped
quaternion orientation, filter scope, source protection, undo/redo, save/reopen
and installation/reload over the stable baseline. Historical ZIPs are unchanged.
The same 15 installation checks also passed separately using the previously
delivered 1.2.0 development ZIP, including a warm native update to 1.3.0.
The Graph Editor was inspected with the generated bone fixture: 241 source keys
became 12 editable keys, and recalculation with Selected Bones Only succeeded.
See [the investigation](../EDITABLE_CURVES.md) for comparison details and the
744,600-key synthetic performance check.

No production character Action was supplied. Local sampled accuracy does not
establish world-space or foot-contact fidelity. Automatic preview, smoothing,
general scalar-channel support and contact locking remain unimplemented. Large
scopes run synchronously; use a small bone selection when exploring settings.

This is a local development package. `release.json` remains at 1.1.1; no release
publication or website deployment is requested.
